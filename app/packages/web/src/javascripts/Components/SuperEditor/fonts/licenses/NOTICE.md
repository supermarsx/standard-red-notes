# Third-party font licences

The `../files/*.woff2` binaries in this directory are redistributed
open-source fonts. Each family's verbatim upstream licence text sits
beside this file, named after the family's woff2 filename stem.

Every family is covered by either the SIL Open Font License 1.1 or the
Ubuntu Font Licence 1.0. Both permit redistribution and bundling
provided the copyright notice and licence travel with the binaries,
which is what this directory is for. No font here is under Apache-2.0.

These are latin-subset woff2 files obtained from the Google Fonts API by
`../fetch-fonts.mjs`; the licence texts were taken from the
corresponding family directory in the upstream `google/fonts` repository.
